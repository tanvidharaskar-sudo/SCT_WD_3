# 🎯 Quiz Game Application

## 📌 Description

The Quiz Game Application is a simple and interactive web-based quiz built using HTML, CSS, and JavaScript. It displays multiple-choice questions, allows users to select answers, and shows the final score at the end.

---

## 🚀 Features

* Multiple-choice questions
* Interactive user interface
* Real-time answer selection
* Score calculation
* Final result display

---

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

---

## 📂 Project Structure

```
quiz-game/
│── index.html
│── style.css
│── script.js
```

*(Or single file version: quiz.html)*

---

## ▶️ How to Run

1. Download or clone this repository
2. Open the file:

   ```
   quiz.html
   ```
3. Run it in any web browser
